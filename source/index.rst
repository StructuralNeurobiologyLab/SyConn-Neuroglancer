Welcome to SyConn-Neuroglancer's documentation!
===============================================

**SyConn-Neuroglancer** is a fork of the `Neuroglancer <https://github.com/google/neuroglancer>`_ 
project. It is a WebGL-based viewer for visualizing volumetric data
and supports querying of 3D-meshes and line-segment based models (skeletons).

.. note::
   This project is under active development.
