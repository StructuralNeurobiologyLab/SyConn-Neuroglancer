Welcome to SyConn-Neuroglancer’s documentation!¶

SyConn-Neuroglancer is a fork of the Neuroglancer project. It is a WebGL-based viewer for visualizing volumetric data and supports querying of 3D-meshes and line-segment based models (skeletons).

Note

This project is under active development.
